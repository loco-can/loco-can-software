# LittleFS data

Generated by `npm run firmware` in the repository root. The folder is filled with gzipped files from the Next.js static export (`out/`).

Copy this directory to `data/` next to `loco-can-software.ino`, then upload the filesystem image:

- Arduino IDE: ESP32 LittleFS Data Upload
- PlatformIO: `pio run -t uploadfs`

The access point serves these files at `http://192.168.4.1/`.
